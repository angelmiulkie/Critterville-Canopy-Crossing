# Critterville-Canopy-Crossing
Individual Game Development Project for class CSS 490: Play as a critter and build a village where other forest critter friends can thrive in!
Critterville: Canopy Crossing is a game where you play as a small critter that comes across a
clearing in a forest and builds a small village where other critter friends can live. Over time, you
can gather materials to build homes, upgrade them, create pathways, benches, and
other public amenities. You can can gather sticks for wood, pebbles for stone, tree sap for
glue, and other small nature-inspired materials to craft.
